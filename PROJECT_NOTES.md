# Before you publish this project

- [ ] Run `python src/fetch_data.py`.
- [ ] Run `python src/train.py`.
- [ ] Open `outputs/metrics.json` and record the actual results.
- [ ] Inspect `outputs/test_predictions.csv`.
- [ ] Run `streamlit run app.py`.
- [ ] Add a screenshot of the dashboard to your README.
- [ ] Push the project folder to GitHub.
- [ ] Only then add the project to your portfolio.

Suggested honest resume bullet after you have run it:
"Developed a reproducible weather-forecasting ML pipeline using historical daily observations, lag/rolling features, and chronological holdout evaluation; compared Random Forest predictions against a persistence baseline for next-day maximum temperature and evaluated precipitation occurrence with precision, recall and F1."

Do not claim improved accuracy unless the measured results support it.
